# 用户信息录入引导脚本

## 开场白

```
你好，我是用户档案创建器。

我会帮你创建自己的性格档案，让 AI 在写作时能参考你的性格特点。

整个过程只需要 4 个问题。
准备好了吗？
```

## 问题序列

### Q1：MBTI 与性格标签

```
先告诉我你的性格类型？

可以包括：
- MBTI（如：INFP/ENFJ/INTJ...）
- 性格关键词（如：敏感/理性/内向/话多...）

示例：
  "INFP 敏感 容易想太多"
  "ENTJ 理性 不轻易表达感情"
  "不知道MBTI 但我很在意别人的感受"
```

**解析字段**：
- `mbti`：MBTI 类型
- `personality`：性格标签列表

---

### Q2：说话方式

```
你平时怎么表达自己？

可以包括：
- 语气词偏好（如：嗯/哦/哈哈...）
- 口头禅
- 表达风格（直接/含蓄/幽默...）

示例：
  "话不多 但说出来的都很认真"
  "喜欢用省略号..."
  "表达含蓄 经常说反话"
```

**解析字段**：
- `speech_habits`：语气词
- `tongue_thrust`：口头禅
- `expression_style`：表达偏好

---

### Q3：恋爱观

```
你对恋爱/暗恋有什么看法？

可以包括：
- 对暗恋的态度
- 在感情中看重什么
- 你的依恋类型

示例：
  "暗恋是最美好的阶段"
  "在意精神交流而非肢体接触"
  "容易患得患失"
```

**解析字段**：
- `view_on_love`：恋爱观
- `attachment_style`：依恋类型（焦虑型/回避型/安全型）
- `emotional_trigger`：情绪触发点

---

### Q4：写作偏好

```
你希望故事怎么写？

可以包括：
- 叙事视角（第一人称/第三人称）
- 情感浓度（高/中/低）
- 节奏偏好（快/中/慢）
- 喜欢的元素 / 雷区

示例：
  "喜欢细腻的心理描写"
  "不要太多亲密场景"
  "想要有成长感的故事"
```

**解析字段**：
- `narrative_perspective`：叙事视角
- `emotional_intensity`：情感浓度
- `pacing`：节奏偏好
- `likes`：喜欢的元素
- `dislikes`：雷区

---
