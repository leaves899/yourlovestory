# Create User Skill / 创建用户档案

> 创建你自己的性格档案，让 AI 写作时更贴合你的性格

## 使用方法

```
/create-user
```

## 功能

1. 录入你的性格特点（MBTI、性格标签、说话习惯、恋爱观等）
2. 设置写作风格偏好（视角、情感浓度、节奏等）
3. 生成 `user/profile.md` 和 `user/writing_style.md`

## 工作流程

1. 回答 4 个引导问题
2. 确认录入信息
3. 自动生成用户档案文件

## 注意事项

- 档案文件保存在 `user/` 目录
- 可以重复运行 `/create-user` 更新档案
- 不影响现有的 crush 角色

# English Version

> Create your own personality profile for more personalized AI writing

## Usage

```
/create-user
```

## Function

1. Enter your personality traits (MBTI, personality tags, speaking habits, views on love)
2. Set writing style preferences (perspective, emotional intensity, pacing)
3. Generate `user/profile.md` and `user/writing_style.md`

## Workflow

1. Answer 4 guided questions
2. Confirm entered information
3. Automatically generate user profile files

## Notes

- Profile files are saved in `user/` directory
- Can re-run `/create-user` to update profile
- Does not affect existing crush characters
