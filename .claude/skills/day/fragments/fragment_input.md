# 碎片输入引导 / Fragment Input Guide

## 功能 | Function

引导用户输入碎片日记的三个维度信息：来源、情绪、内容。

## 使用方法 | How to Use

```
/day 碎片
```

## 工作流程 | Workflow

### 1. 选择写作自由度

```
请选择写作自由度：
1. Raw - 最自由，无引导
2. Guided - 半结构化，提供方向引导
3. Themed - 主题限定
4. Blind - 盲写模式
```

### 2. 选择来源标签

```
请选择来源标签：
1. 用户 - 用户主动发起的消息
2. Crush - 来自 crush 的消息
3. Ambient - 环境触发
```

### 3. 选择情绪标签

```
请选择情绪标签：
1. Positive 😊 - 开心、期待、温暖
2. Negative 😢 - 难过、失落、在意
3. Neutral 😐 - 平静、日常、无特别
4. Mixed 😶 - 复杂、矛盾、说不清
5. 跳过 - 不选择情绪（仅 Raw/Guided 模式可跳过）
```

### 4. 选择方向/主题（按模式）

**Guided 模式：**
```
请选择方向（每日限选一个）：
1. 轻松的 - 记录一些日常小事
2. 有些在意的 - 说说那些让你在意的事
3. 想深入的 - 展开聊聊这个话题
```

**Themed 模式：**
```
请选择主题（单选）：
1. 工作/学习
2. 生活日常
3. 约会/出行
4. 情感交流
5. 兴趣爱好
6. 节日/纪念日
7. 争吵/误会
8. 和好/道歉
```

### 5. 输入碎片内容

```
请输入碎片内容（5-500字）：
（Blind 模式：10-500字）
```

### 6. 碎片记录完成

```
碎片已记录 ✓
继续输入 / 完成今天的碎片 / 编辑碎片
```

## 注意事项 | Notes

- 单日上限 10 个碎片（空内容也计入上限）
- 已完成日期不允许添加新碎片
- 纯表情/符号无法生成叙事
- Blind 模式至少需要 10 字
