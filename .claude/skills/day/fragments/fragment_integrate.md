# 碎片整合逻辑 / Fragment Integration Logic

## 功能 | Function

将多个碎片整合为写作上下文，生成符合 day 写作原则的叙事。

## 整合规则 | Integration Rules

### 1. 单碎片整合

当用户只输入一个碎片时，直接使用该碎片作为写作上下文。

### 2. 多碎片整合

当用户输入多个碎片时，系统按以下规则整合：

#### 来源合并

- 使用所有碎片的来源，按输入顺序排列
- 去重处理

#### 情绪处理

| 情况 | 处理方式 |
|------|----------|
| 情绪相同 | 使用该情绪 |
| 情绪不同 | 使用 mixed |
| 有情绪 + 跳过 | 以有情绪的碎片统计主导情绪 |
| 单个有效情绪 | 直接使用该情绪 |
| 全是跳过 | 无情绪修饰 |

#### 内容拼接

- 按时间顺序拼接
- 使用连接符（、然后、接着、同时、另外）
- 跳过空内容碎片
- 超过 1000 字自动压缩

### 3. 跨天整合

当用户选择继续未完成的碎片时：

#### 整合前置条件

- 系统自动过滤掉超过 7 天的碎片
- 已完成日期不出现在可选列表中
- 用户只能选择近 7 天内的日期进行整合

#### 日期选择机制

- 系统自动列出近 7 天内有未完成碎片的日期
- 默认选中当前日期，用户可勾选其他日期（多选）
- 每个日期显示碎片数量预览（如"周二 · 3个碎片"）

#### 整合后状态转换

- 参与整合的所有日期均标记为已完成
- `completed` 设为 `true`，`writing_context` 填充生成的叙事内容

## Prompt 生成 | Prompt Generation

### Prompt 矩阵

| 来源 \ 情绪 | positive | negative | neutral | mixed | 跳过 |
|-------------|----------|----------|---------|-------|------|
| user | 记录一下，今天我给ta发了什么 | 今天我给ta发了什么，让ta在意了？ | 今天我给ta发了什么？ | 今天我给ta发了什么，心情复杂 | 记录一下，今天我给ta发了什么 |
| crush | ta今天说了什么让你开心的话？ | ta今天说了什么让你在意的话？ | ta今天说了什么？ | ta今天说了什么，心情复杂 | ta今天说了什么？ |
| ambient | 在【环境】时，看到ta的【行为】，感到开心 | 在【环境】时，看到ta的【行为】，感到在意 | 在【环境】时，看到ta的【行为】 | 在【环境】时，看到ta的【行为】，心情复杂 | 在【环境】时，看到ta的【行为】 |

### 占位符填充

- **【环境】**：根据用户输入的环境标签填充
- **【行为】**：根据用户输入的行为标签填充
- **无标签信息时**：使用"某个时刻"或直接省略

## 注意事项 | Notes

- 碎片只是触发器，不是叙事本身
- 系统负责整合碎片为叙事上下文，不改变 day 的写作流程
- 重新生成叙事时，基于当日所有碎片重新整合
