# ADR-0001: 碎片日记架构

## 状态

已批准

## 上下文

yourcrush 需要一个灵活的日记系统，让用户记录与 crush 的日常生活。系统需要支持：
- 多种输入来源（用户主动、crush 动态、环境氛围）
- 灵活的情绪表达
- 智能标签推荐
- 状态管理和版本控制

## 决策

采用**碎片化架构**，以"碎片"（Fragment）作为最小叙事单元：

1. **三层标签体系**
   - 核心维度：来源 + 情绪
   - 场景标签：环境 + 行为
   - 用户标签：自定义

2. **四种写作模式**
   - Raw（自由）
   - Guided（引导）
   - Themed（主题）
   - Blind（盲写）

3. **状态机驱动**
   - 碎片状态：EDITABLE → READONLY_REGENERABLE → READONLY_FINAL
   - 日期状态：IN_PROGRESS → UNFINISHED → EXPIRED → COMPLETED

4. **乐观锁机制**
   - 版本号校验，防止并发冲突

5. **降频策略**
   - 连续跳过 3 次 → 阈值从 50% 提高到 70%

## 后果

### 正面
- 灵活的输入方式，适应不同场景
- 智能标签推荐，减少用户负担
- 状态管理清晰，避免数据混乱
- 版本控制，支持并发编辑

### 负面
- 系统复杂度增加
- 需要更多的测试用例
- 用户学习成本略高
