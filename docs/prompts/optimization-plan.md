# 提示词系统收尾说明

## 目标

本轮收尾的目标不是继续扩写 prompt，而是把已经验证有效的优化内容沉淀成稳定实现，避免后续出现运行时规则、设置页展示和测试口径各自漂移的情况。

## 已确定决策

- 默认系统规则与默认用户模板由 `src/shared/ai/promptBuilder.ts` 统一导出。
- 阶段名称、颜色、描述与规则由 `src/shared/relationship/phase_prompts.ts` 统一导出。
- 设置页只消费 shared 层导出的默认值和阶段配置，不再维护第二份长文本。
- 亲密规则只在 `intimateEnabled=true` 且存在亲密知识库时拼接。
- 亲密规则保持文学化、关系导向、非硬编码，不进入显式流程化内容设计。

## 验证口径

- 测试验证共享来源、拼接条件、阶段规则叠加和 section 顺序。
- 测试不再逐字锁定整段 prompt，只验证结构、边界和关键行为。
- 相关回归覆盖 `promptBuilder`、`phase_prompts` 和 prompt 收尾专用测试。

## 清理范围

- 删除临时 prompt 实验文档、外部网页试验稿和临时生成脚本。
- 保留本说明文档，作为本次 prompt 收尾的仓库内记录。
