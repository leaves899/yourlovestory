# 写作标准规范 / Writing Standards Guide

> 确保叙事质量的一致性和情感深度

---

## 叙事结构 / Narrative Structure

### 三维描写原则

每段叙事应同时包含以下三个维度：

1. **心理描写** - 角色的内心活动、情感变化
2. **环境描写** - 场景氛围、空间细节
3. **动作描写** - 行为动作、身体语言

**示例**：
```markdown
心跳声在耳边放大，我攥紧手机站在咖啡厅门口。

（心理：紧张期待）→（环境：咖啡厅门口）→（动作：攥紧手机）

窗外的雨声、手中的咖啡余温、屏幕上的对话框——每一个细节都被放大。

（心理：细腻感知）→（环境：雨天细节）→（动作：握咖啡）
```

---

## 时间标签格式 / Time Tag Format

### 基本格式

```markdown
## HH:MM · 事件
```

### 使用规则

- 时间使用 24 小时制，格式为 `HH:MM`
- 冒号使用中文冒号 `：`或英文冒号 `:` 均可
- 事件描述应简洁，一行之内

**正确示例**：
```markdown
## 09:00 · 早安
## 14:30 · 午餐
## 21:15 · 晚安
```

**错误示例**：
```markdown
## 9:00 · 早安              # 缺少前导零
## 09:00 · 早上起来吃早餐   # 事件描述过长
```

---

## 禁止项 / Prohibited Elements

### 破折号禁止

叙事中禁止使用破折号（——、--），使用逗号或句号替代。

**错误**：
```markdown
她看着我——眼神里有些复杂。
我很喜欢她——但说不出口。
```

**正确**：
```markdown
她看着我，眼神里有些复杂。
我很喜欢她，但说不出口。
```

### 过度省略号禁止

省略号仅在真正需要停顿时使用，禁止连续使用超过两个。

**错误**：
```markdown
她......不知道该说什么......
```

**正确**：
```markdown
她……不知道该说什么。
```

### 过度形容词禁止

避免在一个句子中使用超过两个形容词。

**错误**：
```markdown
那个温柔美丽善良可爱的女孩对我笑了。
```

**正确**：
```markdown
那个温柔的女孩对我笑了。
```

---

## 角色对话规范 / Character Dialogue Standards

### 对话格式

```markdown
「对话内容。」

「……或者说，这是我的真心话。」
```

### 说话习惯

- 根据 `persona.md` 中定义的语气词和口头禅
- 保持角色说话的一致性
- 对话应推动情节发展

### 省略提示语

叙事中可以使用提示语，但不要每句都加：

**推荐格式**：
```markdown
「明天有空吗？」

她盯着屏幕，手指悬在发送键上。

「有空。」他回复得很快。
```

---

## 结尾格式要求 / Ending Format Requirements

### Day 结尾

每个 Day 结束时，应包含：

1. **情感总结** - 当天的主要情感收获
2. **期待感** - 对明天的期待或暗示
3. **留白** - 不要过于完结，保持想象空间

**示例**：
```markdown
## 23:30 · 夜深

手机屏幕暗下去的那一刻，我躺在床上翻了个身。

心跳还是很快。

明天……她会主动找我聊天吗？
```

---

## 叙事节奏控制 / Narrative Rhythm Control

### 长短句交替

- 情感高潮时使用短句
- 过渡和铺垫时使用长句
- 保持呼吸感，不要一口气写太长

### 场景转换

场景转换时使用空行分隔：

```markdown
窗外的内容已经很暗了。

## 22:30 · 回家路上

街灯把我们的影子拉得很长。
```

---

## 禁止包含真实人物信息 / Prohibition of Real Person Information

- 所有角色均为虚构
- 禁止在文档中出现真实人物姓名、照片描述
- 仅使用昵称和代号

# English Version

# Writing Standards Guide

> Ensuring consistent narrative quality and emotional depth

---

## Narrative Structure

### Three-Dimensional Description Principle

Each narrative passage should contain all three dimensions:

1. **Psychology** - Inner activities, emotional changes
2. **Environment** - Scene atmosphere, spatial details
3. **Action** - Behaviors, body language

**Example**:
```markdown
My heartbeat amplified in my ears as I stood outside the cafe, gripping my phone.

(Psychology: nervous anticipation) → (Environment: cafe entrance) → (Action: gripping phone)

The rain outside, the warmth of coffee in my hand, the chat dialog on screen — every detail was amplified.

(Psychology: delicate perception) → (Environment: rainy day details) → (Action: holding coffee)
```

---

## Time Tag Format

### Basic Format

```markdown
## HH:MM · Event
```

### Usage Rules

- Use 24-hour format, `HH:MM`
- Both Chinese colon `：` and English colon `:` are acceptable
- Event description should be concise, within one line

**Correct Examples**:
```markdown
## 09:00 · Good morning
## 14:30 · Lunch
## 21:15 · Good night
```

**Incorrect Examples**:
```markdown
## 9:00 · Good morning        # Missing leading zero
## 09:00 · I woke up and had breakfast in the morning  # Event too long
```

---

## Prohibited Elements

### Dash Prohibition

Dashes (——, --) are prohibited in narratives. Use commas or periods instead.

**Incorrect**:
```markdown
She looked at me — her eyes were complicated.
I like her — but can't say it.
```

**Correct**:
```markdown
She looked at me, her eyes were complicated.
I like her, but can't say it.
```

### Excessive Ellipsis Prohibition

Ellipsis should only be used for genuine pauses. Do not use more than two consecutive.

**Incorrect**:
```markdown
She......didn't know what to say......
```

**Correct**:
```markdown
She… didn't know what to say.
```

### Excessive Adjective Prohibition

Avoid using more than two adjectives in one sentence.

**Incorrect**:
```markdown
That gentle beautiful kind lovely girl smiled at me.
```

**Correct**:
```markdown
That gentle girl smiled at me.
```

---

## Character Dialogue Standards

### Dialogue Format

```markdown
「Dialogue content.」

「…Or perhaps, this is my true feelings.」
```

### Speaking Habits

- Follow the tone words and catchphrases defined in `persona.md`
- Maintain consistency in character speech
- Dialogue should drive plot development

### Omitting Speech Tags

Narrative can use speech tags, but not for every line:

**Recommended Format**:
```markdown
「Are you free tomorrow?」

She stared at the screen, her finger hovering over the send button.

「Yes.」He replied quickly.
```

---

## Ending Format Requirements

### Day Ending

Each Day should end with:

1. **Emotional summary** - Main emotional takeaway of the day
2. **Anticipation** - Anticipation for tomorrow or a hint
3. **White space** - Don't over-conclude, keep room for imagination

**Example**:
```markdown
## 23:30 · Late night

The moment my phone screen went dark, I turned over in bed.

My heart was still beating fast.

Tomorrow… will she take the initiative to chat with me?
```

---

## Narrative Rhythm Control

### Alternating Long and Short Sentences

- Use short sentences during emotional climax
- Use long sentences for transitions and setup
- Maintain breathing rhythm, don't write too long in one breath

### Scene Transitions

Use blank lines to separate scene transitions:

```markdown
The lights outside had already dimmed.

## 22:30 · On the way home

Street lamps stretched our shadows long.
```

---

## Prohibition of Real Person Information

- All characters are fictional
- Real person names and photo descriptions are prohibited in documents
- Use only nicknames and code names
