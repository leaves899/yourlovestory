# PRD — yourcrush 模拟恋爱叙事写作工具链

**产品名称**：yourcrush — 模拟恋爱叙事写作工具链

**背景**：用户希望将与暗恋对象的互动记录下来，生成有温度、有心理深度的第一人称叙事文本。现有方案存在明显痛点：

- **传统日记应用**（Day One、Flomo）：只能记录事实，缺乏叙事生成能力，无法将碎片素材编织成有温度的故事
- **通用 AI 写作工具**（ChatGPT、Claude 直接对话）：缺乏角色一致性，每次对话都是独立的，无法积累关系记忆和人物性格
- **恋爱模拟游戏**：角色固定、剧情预设，无法自定义暗恋对象，且是被动消费而非主动创作

yourcrush 的核心价值：将暗恋对象"蒸馏"为 AI Skill，让 AI 成为一个了解你们故事的写作伙伴，随时帮你把心动瞬间变成可以反复阅读的故事。

**核心能力**：**生成有温度、有心理深度的第一人称叙事文本**

**目标用户**：

- 有暗恋对象、想把心动瞬间变成故事的人
- 喜欢第一人称恋爱叙事写作的人
- 想用 AI 辅助生成有情感深度的日常故事的人

**客户端平台**：Windows + macOS + Linux（Electron 桌面应用）

**技术门槛**：下载安装包即可使用，无需技术背景

**核心流程**：

```
记录素材 → 生成叙事 → 阅读故事
   ↑                    │
   └────── 积累 ←───────┘
```

### 3.4 叙事质量标准

| 维度 | 要求 | 示例 |
|------|------|------|
| 时间标签 | 每个场景有明确时间 | `## 14:30 · 咖啡店` |
| 对话格式 | 使用「」格式 | `「迟到三分钟。」她说。` |
| 心理描写 | 内心活动、想法 | `我假装没注意到。` |
| 环境描写 | 场景细节、氛围 | `阳光从侧面打过来，头发边缘镀了一层淡金色。` |
| 动作描写 | 肢体语言、微表情 | `她把手机扣在膝盖上，笑了。` |
| 情感结尾 | 总结 + 期待 + 留白 | `那天之后，我开始期待下一次偶遇。` |

### 3.6 安全设计

| 安全措施 | 说明 |
|----------|------|
| IPC 白名单 | contextBridge 只暴露 8 个安全 API |
| 参数校验 | TypeBox 运行时验证所有输入 |
| XSS 防护 | DOMPurify 净化 AI 输出 |
| 路径遍历防护 | Slug 正则校验 `^[a-z0-9-]+$` |
| 敏感操作禁止 | BLOCKED_CHANNELS 阻止 shell.openExternal 等 |

### 3.7 数据本地存储与安全

```
数据存储结构：

d:\CLAUDECODE\yourcrush\
├── crushes/                    # 角色数据（.gitignore 排除）
│   ├── TEMPLATE/               # 空白模板
│   └── <slug>/                 # 具体角色
│       ├── meta.json           # 元数据（姓名、昵称、创建时间）
│       ├── persona.md          # 5层性格画像
│       ├── memory.md           # 关系记忆
│       ├── SKILL.md            # AI 指令文件
│       ├── CONTEXT.md          # 压缩上下文（自动生成）
│       ├── INTIMATE_KNOWLEDGE.md # 亲密知识库（默认关闭）
│       └── memories/chats/     # 叙事存档（核心数据）
├── user/                       # 用户档案（.gitignore 排除）
│   ├── profile.md              # 用户性格
│   └── writing_style.md        # 写作偏好
└── scripts/                    # 工具脚本
    ├── fragment_manager.py     # 素材管理
    ├── tag_recommender.py      # 标签推荐
    └── toggle_intimate.py      # 亲密内容开关
```

**安全机制**：

- 所有数据本地存储，不上传任何服务器
- `.gitignore` 排除 `crushes/*/` 和 `user/`，防止意外提交
- 亲密内容默认关闭，需显式启用（编辑 `crushes/<slug>/.intimate_config` 写入 `intimate=true`，原 `toggle_intimate.py` 已迁移为 `src/shared/persistence/intimateToggle.ts`）
- CI 流水线检测真实人物信息泄露（小明、xiaoming、李薇等）

### 3.8 离线运行支持

- **完全离线**：所有 Skill 文件、Python 脚本、角色数据均本地存储
- **AI 依赖**：叙事生成需要调用 Claude API，需联网
- **降级方案**：无网络时可手动编辑 `memories/chats/` 中的 Markdown 文件

## 5. 用户故事与验收标准

### US-1: 生成日常叙事（核心功能）

**Given** 用户已有角色档案和若干素材记录
**When** 用户点击「生成叙事」按钮
**Then** 系统基于当日素材生成完整故事，流式渲染到主内容区

**验收标准**：
- [ ] 生成过程有加载动画
- [ ] 叙事实时流式渲染（打字机效果）
- [ ] 叙事包含时间标签（`## HH:MM · 事件`）
- [ ] 包含对话（使用「」格式）
- [ ] 包含三维描写（心理 + 环境 + 动作）
- [ ] 结尾有情感总结 + 期待感 + 留白
- [ ] 不使用破折号、不过度使用省略号
- [ ] 生成完成后光标闪烁动画停止

### US-2: 浏览叙事历史

**Given** 用户已生成多日叙事
**When** 用户在侧边栏选择历史日期
**Then** 系统显示该日期的完整叙事

**验收标准**：
- [ ] 日期选择器支持手动输入和日历选择
- [ ] 叙事以 Markdown 格式渲染
- [ ] 无叙事时显示「暂无叙事，点击生成」提示
- [ ] 支持「今日/昨日/本周/全部」快速筛选

### US-3: 记录素材

**Given** 用户已创建角色，当前处于任意关系阶段
**When** 用户在底部输入框输入「今天在食堂偶遇她，她穿了件浅蓝色的裙子」，选择来源（用户）和情绪（😊），点击「记录」
**Then** 系统保存素材到本地，显示在侧边栏列表中

**验收标准**：
- [ ] 输入框支持多行文本
- [ ] 来源选择器有三个选项（用户/Crush/环境）
- [ ] 情绪选择器有四个选项（开心/在意/平静/复杂）
- [ ] 保存成功后输入框自动清空
- [ ] 素材立即显示在侧边栏列表
- [ ] 保存失败时显示友好错误提示

### US-4: 创建角色档案

**Given** 用户已安装 yourcrush 桌面应用
**When** 用户点击「创建角色」按钮，输入暗恋对象的基本信息（代号、性格、外貌）
**Then** 系统生成完整的角色档案，后续叙事可基于此角色生成一致的内容

**验收标准**：
- [ ] 界面引导清晰，无需阅读文档即可完成
- [ ] 生成的 persona.md 包含 5 层结构（硬规则、身份、说话风格、情感模式、关系行为）
- [ ] 生成的 memory.md 包含基本信息和初始关系记忆
- [ ] 创建完成后自动切换到新角色

### US-5: 切换角色

**Given** 用户已创建多个角色
**When** 用户在侧边栏角色选择器中选择另一个角色
**Then** 系统切换到新角色，加载对应的叙事和素材

**验收标准**：
- [ ] 切换过程有加载状态
- [ ] 主内容区更新为新角色的叙事
- [ ] 侧边栏素材列表更新为新角色的数据
- [ ] 切换失败时显示友好错误提示
